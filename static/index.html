Playback

Stop

Stops the current playback or recording. Switch to preview/output mode first if needed.

Jog

Frame-accurate positioning. Supports absolute or relative ±timecode.

Shuttle

Continuously variable speed from -5000 to 5000%. 0 = pause.

Go To

Spec: only one parameter/value pair per goto command. Use ± prefix for relative navigation.

Clip ID: absolute ID, +n or -n for relative (clamped to first/last clip).

Play Range

Choose exactly one method: Clip ID, Timecode range, or Timeline frames.

Play on Startup

Determines deck behaviour on power-up.

Play Option

Determines which frame is displayed when playback stops.

Preview Mode

Switches between preview (input) and output mode. Stop recording before switching to output.

Utility Commands

Identify

Flash the front panel LEDs to physically identify a unit.

Watchdog

Device closes the connection if no command is received within period seconds. Set period ≤ 0 to disable. The app sends a ping automatically to maintain the connection.

Reboot Device

⚠ The device will reboot and the connection will be closed.

Close Connection

Instruct the HyperDeck to cleanly close the TCP connection.

Raw Command

Send any raw protocol command. Use \n for multiline blocks.
